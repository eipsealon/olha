Свой чат на бесплатной базе Supabase. Пять минут — и готово.

  1. Зарегистрируйся на supabase.com и создай проект (регион — Frankfurt, он ближе всего).
  2. Открой SQL Editor, вставь скрипт из кнопки ниже и нажми Run.
  3. В Authentication → Sign In / Providers → Email выключи Confirm email, чтобы друзьям не пришлось подтверждать почту.
  4. В Project Settings → API скопируй сюда Project URL и ключ anon public.

Чтобы друзья не вводили это вручную — открой index.html в блокноте и впиши URL и ключ в CONFIG в самом верху скрипта.
